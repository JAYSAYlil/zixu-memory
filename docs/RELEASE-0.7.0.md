# 自叙 0.7.0

## 本次更新

- 询问自己的回答要求区分已确认认识、可能倾向和资料缺口；拒绝不存在或缺失的引用。点击依据可打开记录或查看、修正认识。
- 增加“符合我／不太符合／现在变了”反馈入口，进入用户编辑和确认流程后才保存；不会自动采纳模型生成的认识。
- 安卓完整备份支持密码加密：PBKDF2-HMAC-SHA256（600000 次）派生密钥，AES-256-GCM 逐帧认证，随机 32 字节盐，序号与结束帧检测乱序、篡改及截断。密码不持久保存。保留普通备份和旧格式导入。
- 显示最近发起加密备份的时间；系统分享面板关闭不能证明用户保存成功，因此不会显示“已安全备份”。恢复前仍展示导入摘要并保留撤销恢复能力。
- 详情显示附件大小与转写状态，支持系统打开或分享；转写失败后显示原因及重试入口。
- 存储管理按大小列出当前附件，分类统计空间；移除前显示文件及关联记录，保留文字并标记依赖认识需复核。恢复副本保护的文件可能不会立即释放。
- 检索加入低权重同义词扩展、文本缓存和命中附近摘要。数据库按 200 条游标分页读取，避免单次传递全部序列化记录。
- 增加首次使用引导，说明无需 AI 的功能、主动发送资料的范围和备份方式。
- 修复普通文件附件被旧校验规则拒绝的问题。
- 启用 Release 代码与资源裁剪，构建同步按精确文件路径逐个核验 SHA-256；设置页版本来自应用配置。

## 验证与边界

- 类型检查与 32 项核心测试通过，包含错误密码、篡改、截断、乱序、普通文件加密备份恢复、450 条相同日期的分页边界、回答引用校验。
- 新功能网页交互与 320/393/620 宽度的布局回归通过。只使用虚构数据和模拟模型接口。
- Android Release 构建通过；22 个应用源码模块与 Metro 源码映射一致，APK 内 bundle 哈希与本次构建一致，版本和签名已核验。
- 没有连接真机：系统文件分享、真实软键盘、录音中断、旧版覆盖升级及 R8 后的全面原生运行验收尚未完成。
- 数据库虽然分批读取，但仍在完成加载后保留全量内存快照，以保持现有备份、引用和修改语义。并未实现完全按需加载，超大库内存优化仍需进一步改造。
- 网页是预览环境，加密完整备份在安卓应用中使用。普通导出、本机数据库与恢复副本不因导出加密而自动加密。
- 同义词扩展属于本地词法检索，不是向量检索。长录音重试仍受服务商文件上限约束，不承诺超限录音都能转写。
