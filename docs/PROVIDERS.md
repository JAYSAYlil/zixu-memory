# 供应商预设

预设只填写兼容接口地址；模型 ID 可以自行填写，未内置 ID 的供应商请从自己的控制台复制可用模型。预设存在不代表当前账户有权限或额度。

核对时间：2026-09-13。参考供应商官方文档：

- DeepSeek：https://api-docs.deepseek.com/
- 千问：https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope （预设使用仍可用的北京通用域名，也可改填业务空间专属域名）
- Kimi：https://platform.kimi.com/docs/api/overview
- 智谱：https://docs.bigmodel.cn/api-reference/文件-api/文件列表
- 硅基流动：https://docs.siliconflow.cn/docs/userguide/quickstart
- OpenRouter：https://openrouter.ai/docs/quickstart
- Gemini：https://ai.google.dev/gemini-api/docs/openai

目前实现 Chat Completions 文本协议，未实现各家的原生图片、音频或工具调用接口。
