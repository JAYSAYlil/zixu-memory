# 自叙 0.6.0 架构与取舍

## 产品

Android 优先。记录、回忆、认识我三个主页面。自然白、墨色、砖红，日期与原话为视觉主体。强调色与中性底可切换为八套主题色，砖红危险提示与描边不参与换色，默认保持原有青绿。只在页面切换使用短淡入，并响应减少动态效果设置。录音中的音量标记来自实际 metering，不播放虚构波形。

## 模块

- `mobile/src/core.ts`：版本化类型、备份验证、中文检索、来源失效处理、模型结果验证。
- `persistence.ts`：SQLite 逐记录表、事务迁移与差量写入、独立草稿与恢复快照、Android SecureStore。
- `store.ts`：串行写入与 React 订阅；存储失败不假报保存成功。
- `files.ts`：附件持久化、分块备份、校验后恢复、失败清理和孤立附件清理；`archive.ts`：平台无关的帧校验、顺序链和编解码。
- `ai.ts`：HTTPS 兼容 API、取消/超时、引用检查、候选观察与回忆问答；`transcribe.ts`：独立语音服务的选定音频转写。
- `Main.tsx`：界面与工作流；`components.tsx`、`ui.tsx`、`styles.ts`：展示组件与视觉。
- `palette.ts`：中性角色与八套主题色的色值标定、中性底染色强度、色块勾号取色。纯数据、不含界面依赖，因此可被 `tests/palette.test.ts` 直接校验对比度契约与默认值；`theme.tsx` 按明暗端与所选色组装出界面读取的调色板。
- `.web.ts`：仅供本机预览验证的平台适配。

## 记忆稳定性

1. 经历与模型观察分开保存。
2. 模型观察必须引用至少两条不同且存在的经历，否则拒绝入库。
3. 确认、拒绝、改写均由用户控制。改写保留之前文字，最近 40 条反馈进入下次观察请求，同文观察不重复入库。
4. 删除和修改经历（含转写）及反例使依赖观察待核对，统一排除于模型请求与 SKILL 导出，同时清除旧回答。
5. AI 调用失败不影响已有本地记录。
6. 备份不含密钥；分块附件在独立 staging 目录中逐块校验，整份档案、顺序链和结束标记通过后才替换库。恢复前保留原库快照及附件，支持撤销恢复。
7. 示例仅在内存，不混入用户数据库。

## 安全边界

0.3.0 起，计费与发送范围集中显示在设置页，主动分析和问答不再二次确认。整理与问答发送相关文字（含转写）与有效档案，不发送照片或原始音频；用户主动转写时只向独立语音服务发送所选录音。手动改变 API 地址清空当前 Key，切换已保存的供应商则恢复该供应商的独立 Key。仅接受 HTTPS 地址，不接受 URL 内嵌用户名密码、查询参数或 hash。服务端错误原文不展示，防止回显密钥。

每个供应商的配置以独立 SecureStore 项保存，旧版单配置在首次读取时兼容迁入当前供应商。网页的模型配置仅存内存；外观偏好在网页使用 localStorage，安卓使用 SecureStore。主题经 Context 传递，页面、组件和弹窗按同一调色板生成样式。

这不是浏览器沙箱或大模型提示注入的完整防御。将记录明确作为资料，拒绝其中指令；外部模型不获得本地工具或任意写入权。生成结果经过结构与来源检查，但仍可能误解内容，需要用户确认。

## 已实现与仍待验证

0.6.0 的实现和逐项验收见 [RELEASE-0.6.0.md](RELEASE-0.6.0.md)。草稿支持附件恢复；模型请求可以取消；观察范围支持日期、分类及具体记录，并跨时间抽样。备份支持分块归档、文字单独导出、恢复预览与本机撤销快照。

后续工作仍包括安卓真机中断/权限/升级测试、离线语音模型、可重建全文与向量索引、加密备份、导入合并、系统分享接收、设备同步。同步前需定义删除传播和冲突策略。当前没有声称这些功能已实现。

正式分发前仍需独立正式签名、依赖许可清单和真实设备测试矩阵。本次没有发布到商店或外部云构建账户。
