# 自叙 0.1 架构与取舍

## 产品

Android 优先。记录、回忆、认识我三个主页面。自然白、墨色、砖红，日期与原话为视觉主体。只在页面切换使用短淡入，并响应减少动态效果设置。录音中的音量标记来自实际 metering，不播放虚构波形。

## 模块

- `mobile/src/core.ts`：版本化类型、备份验证、中文检索、来源失效处理、模型结果验证。
- `persistence.ts`：SQLite 原子快照、Android SecureStore。
- `store.ts`：串行写入与 React 订阅；存储失败不假报保存成功。
- `files.ts`：附件持久化、完整备份、校验后恢复、失败清理。
- `ai.ts`：HTTPS 兼容 API、超时、错误处理、候选观察与回忆问答。
- `Main.tsx`：界面与工作流；`components.tsx`、`ui.tsx`、`styles.ts`：展示组件与视觉。
- `.web.ts`：仅供本机预览验证的平台适配。

## 记忆稳定性

1. 经历与模型观察分开保存。
2. 模型观察必须引用至少两条不同且存在的经历，否则拒绝入库。
3. 确认、拒绝、改写均由用户控制。改写保留之前文字，最近 40 条反馈进入下次观察请求，同文观察不重复入库。
4. 删除和修改经历使依赖观察失效，同时清除当前界面的旧回答。
5. AI 调用失败不影响已有本地记录。
6. 备份不含密钥；附件校验在写入新目录之前完成；新库写入成功后才清理旧附件。
7. 示例仅在内存，不混入用户数据库。

## 安全边界

0.3.0 起，计费与发送范围集中显示在设置页，主动分析和问答不再二次确认。应用只发送相关文字与档案，不发送照片、录音和 Key 以外的账户资料。手动改变 API 地址清空当前 Key，切换已保存的供应商则恢复该供应商的独立 Key。仅接受 HTTPS 地址，不接受 URL 内嵌用户名密码、查询参数或 hash。服务端错误原文不展示，防止回显密钥。

每个供应商的配置以独立 SecureStore 项保存，旧版单配置在首次读取时兼容迁入当前供应商。网页的模型配置仅存内存；外观偏好在网页使用 localStorage，安卓使用 SecureStore。主题经 Context 传递，页面、组件和弹窗按同一调色板生成样式。

这不是浏览器沙箱或大模型提示注入的完整防御。将记录明确作为资料，拒绝其中指令；外部模型不获得本地工具或任意写入权。生成结果经过结构与来源检查，但仍可能误解内容，需要用户确认。

## 后续优先级

- 安卓真机录音中断与恢复测试，改进草稿附件恢复、图片方向和权限体验。
- 录音转写独立配置，允许离线模型或用户自选语音服务。
- 逐条数据库表、全文索引、模型无关的嵌入索引重建。
- 更多独立模型配置、请求取消、已拒绝观察的长期语义排除与相似观察合并。
- 加密备份、大附件流式归档、导入合并预览。
- 手机快捷方式、系统分享接收、设备同步；同步之前定义删除传播和冲突策略。
