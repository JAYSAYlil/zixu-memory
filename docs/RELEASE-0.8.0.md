# 自叙 0.8.0

## 本次更新

- 设置页外观板块新增主题色切换：八套主题色（青绿、海蓝、靛蓝、紫罗兰、品红、暖橙、松绿、石墨蓝），每套分别标定浅色端与深色端，点选即时生效并持久保存；标题显示当前色名，选中色块带描边与勾号，勾号颜色按该端实际明度取。
- 主题色覆盖强调色家族：主按钮、选中态、日期数字、来源编号、底部导航、分类筛选、日历选中日、加载指示与勾选块。中性底 wash 随所选色轻微染色，描边、纸面、墨色与砖红危险提示固定不随色相改变。
- 默认青绿沿用应用既有数值，未改选其他色时界面与 0.7.0 一致。「已确认观察」的圆点跟随主题色，青绿端保留既有橄榄绿次要色。
- 色块行按可用宽度等分排布，320 宽度自动收缩色块直径，触控高度保持 44。
- 暖橙浅色端强调色定为 `#BB5800`：原标定值上的白字对比度只有 4.45，不足 AA，加深一档后为 4.6。
- 主题色偏好与外观模式同处保存：安卓存入 SecureStore，网页预览存入 localStorage；不进入记忆备份，也不参与 SKILL.md 导出。
- 构建脚本 `scripts/build-android.ps1` 与 `scripts/sync-build.ps1` 改为 UTF-8 带 BOM 保存：两者含中文字符串，Windows PowerShell 5.1 对无 BOM 的 .ps1 按 ANSI 代码页读取会解析失败或在 `ConvertFrom-Json` 处抛错。已在 `docs/ANDROID-BUILD.md` 记下这条约束。

## 验证与边界

- 类型检查通过。39 项核心测试通过，其中新增 7 项调色板契约：默认青绿与中性底必须精确复现 0.7.0 数值、八色在两端互不相同、容器与按钮文字对比度不低于 4.5、强调色与确认点不低于 3、中性底染色后正文与次级文字仍达标、砖红与描边不参与换色。
- 新增主题色网页回归 37 项断言通过：默认值、换色后强调色与中性底同时变化、跨刷新保留、深色端换色、八色逐个切换后三个页面均生效、320 宽度排布不溢出不重叠、复位后与初始一致，且无页面报错。截图在 `artifacts/theme-accent/`。
- 布局与增强两套既有网页冒烟通过。其余八套既有脚本自 0.7.0 加入首次引导后在全新浏览器配置下必然失败，已还原到未改动的 0.7.0 复核确认与本次无关，记录在 `docs/TESTING.md`，本次未修。
- 包体核验：versionName 0.8.0、versionCode 30、仅 arm64-v8a、targetSdk 36、minSdk 24；APK 内 `index.android.bundle`（Hermes 字节码）哈希与本次构建产物一致，且包内字符串表含 `主题色`、`石墨蓝`、`theme-accent-`、`#BB5800`，同一探测在未改动的 0.7.0 包内全部不存在；Metro 源码映射中 24 个应用模块与工作区源码逐一同哈希，含新增的 `src/palette.ts`；签名证书与 0.7.0 相同（`fac61745…33b9c`）。构建副本按文件相对路径同步并逐个核验 SHA-256，共 54 个文件。
- 安装包在脚本加 BOM 之前构建。该改动只影响 PowerShell 如何读取构建脚本，不参与 JS 打包与原生编译，包体内容不受影响；`交付记录/v0.8.0/` 内的源码包为加 BOM 之后的当前源码。
- 没有连接真机：色块行在系统大字体与真实软键盘下的排布、跟随系统在安卓厂商 ROM 上的表现、覆盖安装后的偏好保留均未验收。
- 应用图标与启动图仍是既有砖红品牌色，属 prebuild 产物，不随主题色改变。
- 本机数据库与普通备份不因本次改动加密；安卓密码加密备份沿用 0.7.0 行为。
- 网页预览与安卓共用同一套色值定义，但网页端不提供加密完整备份。
