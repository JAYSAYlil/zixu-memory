# 自叙 0.8.2

## 更新

- 设置页在同一会话内关闭后重新打开，会恢复离开时的滚动位置；只作用于设置页。
- 价值观中的反例改为可点击的原记录摘要，显示日期与真实文字、最多两行截断，并保留明显卡片间距；已删除引用不显示无效入口。
- 网页备份导入在开始忙碌状态更新前同步启动文件选择，保留浏览器用户手势；恢复期间仍由操作锁防止重复执行。

## 安装包

Android ARM64 APK：[zixu-0.8.2-arm64.apk](https://github.com/JAYSAYlil/zixu-memory/releases/download/v0.8.2/zixu-0.8.2-arm64.apk)，沿用既有预览签名，可覆盖安装同签名旧版本。SHA-256：`4898DB7E2CF3CE853D63C023DD32F8B3841B85DB6EDC8264F52B7E8D912D5D8C`。

## 验证

- `npm run typecheck` 通过；`npm test` 40 项通过。
- 网页导出和 12 套网页回归通过，包括首次引导、模拟 AI、附件、价值观反例摘要、设置页滚动位置及 2,001 条记录可靠性流程。
- 可靠性测试在真实按钮点击前注册 Playwright 文件选择器事件，避免用 2 秒超时误判延迟事件；产品修复则是先在用户手势内启动文件选择，再呈现忙碌状态，两者分别验证。
