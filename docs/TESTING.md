# 0.3.0 验证记录

## 已通过

- Android ARM64 Release APK 构建成功（Gradle 9.3.1、JDK 17、SDK 36、NDK 28.2）。
- APK 包名 `app.zixu.memory`，目标版本 `0.3.0`，最低 API 24 / Android 7，目标 API 36；本次构建与签名核验结果见交付记录。
- 安装包内含 `assets/index.android.bundle` 与 ARM64 原生库，不需要 Metro 提供代码。
- TypeScript 应用代码类型检查。
- Expo 网页生产包导出。
- 7 项核心自动化测试：删除来源联动、修订历史、损坏备份验证、附件路径验证、虚构来源拒绝、HTTPS 目标校验、中文短词搜索。
- Chrome 手机尺寸（393 × 852）界面自动化：示例隔离、记录保存、页面刷新后恢复、搜索、修订、自我档案保存。
- 模拟 AI 接口完整工作流：自备 Key 配置、有效来源观察、用户修正与历史、回忆问答、备份不含 Key、删除来源后的观察清理、备份恢复。

模型接口测试使用 Playwright 拦截虚构域名，未消耗真实 API 额度。网页存储适配与安卓 SQLite 不同，因此网页通过不等于原生功能已经真机验收。

新增 `node scripts/interaction-smoke.cjs` 已通过：供应商独立 Key/模型恢复、成功/401 失败提示、浅深色偏好与系统模式、模拟麦克风暂停/继续/完成、录完继续编辑、详情修改后返回、统一取消弹窗、320px 窄屏。截图来自 Chromium 网页预览；录音使用浏览器模拟麦克风，不是真机录音测试。
